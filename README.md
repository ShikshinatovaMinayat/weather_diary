# Weather Diary — Личный дневник наблюдений за погодой

**Автор:** Шихшинатова Минаят Абдурашидовна

## Что это за программа

«Weather Diary» — это настольное приложение с графическим интерфейсом (GUI), которое помогает вести удобный журнал погоды.  
Оно подойдёт для ежедневных заметок о температуре, осадках и общем состоянии погоды.

### Основные возможности

- Внесение новой записи с указанием даты, температуры, текстового описания и отметки об осадках
- Просмотр всех добавленных записей в виде таблицы
- Гибкая фильтрация:
    - по конкретной дате
    - по температуре (например, показывать только тёплые дни выше выбранного значения)
- Удаление ненужных записей через контекстное меню (правой кнопкой мыши)
- Выбор даты через встроенный календарь — удобно и наглядно
- Сохранение всех данных в JSON-файл и загрузка из него
- Автоматическая проверка ввода: дата, число, описание

## Что потребуется для запуска

- Python версии 3.6 или новее
- Только стандартные библиотеки:  
  `tkinter`, `json`, `datetime`, `os`  
  (дополнительно ничего устанавливать не нужно)
