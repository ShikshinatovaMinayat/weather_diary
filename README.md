# Weather Diary - Дневник погоды

**Автор:** Шихшинатова Минаят Абдурашидовна

## Описание программы

Weather Diary - это приложение с графическим интерфейсом для ведения дневника погоды. 
Программа позволяет:
- Добавлять записи о погоде (дата, температура, описание, наличие осадков)
- Просматривать все записи в удобной таблице
- Фильтровать записи по дате и температуре
- Сохранять данные в JSON-файл и загружать из него
- Использовать удобный календарь для выбора даты
- Удалять записи через контекстное меню

## Требования

- Python 3.6 или выше
- Только стандартные библиотеки Python (tkinter, json, datetime, os)
